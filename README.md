# Balle Bot: landing page

**[Ver online](https://rafaeldiasfilho.github.io/balle-bot-landing-page/)**

Landing page de um bot fictício para moderar comunidades do Discord.

Projeto de estudo de HTML e CSS feito a partir de um layout do canal do Ballerini.

## Como ver

Abra o `index.html` no navegador.

## O que pratiquei

- Montagem de uma landing page a partir de um layout pronto
- Posicionamento com Flexbox
- Uso de imagens SVG
